### LexiGo 3.5.9

- 词库底部显示「共 N 个 · 第 X / Y 页」，根据当前搜索和筛选计算页数。删除或恢复词条后会自动调整到有效页。
- Windows 默认 Enter 展开释义，1 记录「没记住」，2 记录「记住了」并翻页。记录遗忘后用 Enter 或点击「下一单词」继续。
- Windows 可自定义五项复习快捷键，支持按键录入、冲突提示和恢复默认。设置保存在本机数据目录，复习页和使用说明随配置更新。
- 尚未翻页的「没记住」会在原卡片撤销，保留释义、备注和滚动位置。已经翻页时仍可返回上一张卡片。

| 文件 | 用法 |
|---|---|
| `LexiGo-Android-3.5.9.apk` | Android 安装包，可覆盖安装使用同一发行证书的旧版。 |
| `LexiGo-Setup-3.5.9.exe` | Windows x64 安装版，可选择安装和数据目录。 |
| `LexiGo.exe` | Windows x64 便携版，下载后可直接运行。 |

Windows 文件沿用此前的发行签名策略。
