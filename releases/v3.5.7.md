### LexiGo 3.5.7

- 展开释义时先测量内容，再在下一帧同步启动卡片、箭头和 Android 作答栏。手动收起继续使用原有节奏。
- 普通翻页和撤销时，卡片外框随滑出、滑入接续改变高度。等待作答结果期间保持中间高度。
- 「记忆联想」优先显示自定义构词。留空时使用本地自动构词，记忆技巧接在下方。原始词源保留在折叠区，编辑时可选用其中的内容。
- 原七字段 CSV 继续可用。词库导出使用可选的 `rawEtymology` 保存原始词源。含新资料字段的 `.lexi` 文件请用 3.5.7 或更新版本读取。

| 文件 | 用法 |
|---|---|
| `LexiGo-Android-3.5.7.apk` | Android 安装包，可覆盖安装使用同一发行证书的旧版。 |
| `LexiGo-Setup-3.5.7.exe` | Windows x64 安装版，可选择安装和数据目录。 |
| `LexiGo.exe` | Windows x64 便携版，下载后可直接运行。 |

Windows 文件沿用此前的发行签名策略。
