### LexiGo 3.5.6

- 「添加单词」提供 CSV 导入指南、可复制的示例和两份 UTF-8 模板。可以直接粘贴带表头的 CSV，也可继续使用 TXT、JSON 和手动输入。
- 复习卡片在「记忆联想」中优先显示词根词缀和记忆技巧，自动生成的内容可作为补充。个人备注仍可单独编辑。
- 展开或收起释义时卡片连续伸缩，Android 作答栏和展开箭头与之同步。
- Android 导出、分享和备份采用 `.lexi` 文件名。旧扩展名的有效文件可通过各自的导入或恢复入口按内容校验。

| 文件 | 用法 |
|---|---|
| `LexiGo-Android-3.5.6.apk` | Android 安装包，可覆盖安装使用同一发行证书的旧版。 |
| `LexiGo-Setup-3.5.6.exe` | Windows x64 安装版，可选择安装和数据目录。 |
| `LexiGo.exe` | Windows x64 便携版，下载后可直接运行。 |

Windows 文件沿用此前的发行签名策略。
