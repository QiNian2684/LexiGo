### LexiGo 3.5.5

- Android 收起释义时，在复习卡片正面向下滑即可展开。展开后可继续上下滚动。
- Android 作答栏随释义和卡片动画升起或下沉。「没记住」第一次作答时留在原卡，按钮更新为「下一单词」。
- 两端设置按学习规则、时间与考试、复习显示、外观、词典和数据管理整理。学习日结束时间的箭头与其他选择控件对齐。

| 文件 | 用法 |
|---|---|
| `LexiGo-Android-3.5.5.apk` | Android 安装包，沿用原包名和发行证书。仅用 APK 在 Android 16 验证全新安装和覆盖升级 3.5.3。 |
| `LexiGo-Setup-3.5.5.exe` | Windows x64 安装版，可选择安装和数据目录。 |
| `LexiGo.exe` | Windows x64 便携版，适合直接运行。 |

Windows 文件通过安装和便携数据验证，沿用未做 Authenticode 签名的发行策略。
