# LexiGo 2.1.3

个人使用的英语词库与复习软件。支持 Windows 10/11 x64 和 Android 9 及以上。两端共用词典、SQLite 表结构、数据交换格式和复习逻辑。

## 使用

Windows 双击 `LexiGo.exe`，应用通过 WebView2 Runtime 打开本地窗口。Windows 端用同级 `Data/WebView2` 持久保存窗口配置。若缺少运行时，请从 Microsoft 安装 Evergreen WebView2 Runtime。Android 安装 `LexiGo-Android-2.1.3.apk` 后打开「LexiGo」。运行无需安装 Go、Python 或数据库服务器。

1. 在「添加单词」粘贴英文或通过「导入 TXT 文件」打开词表，点击「预览导入」，核对新增及重置数量，再确认。
2. 在「复习」点击「开始复习」。Windows 的 Enter 展开释义，1 没记住，2 记住了。点「没记住」先保存一次遗忘并留在原卡片。点「下一单词」或再按 1 只翻页。两颗作答按钮固定在底部。点卡片右上角的「今日直接过关」可立即完成该词当天目标，展开或收起释义时都能使用。Android 展开释义后左滑可记住，记录遗忘后左滑只翻页。在复习页从左向右滑动可撤销上一次作答，手势可从卡片外开始。Windows 可点击「撤销上一次」或按 `Ctrl+Z`。通过导航离开复习时会保存已有进度。
3. 展开卡片即可写多行个人备注。在「编辑卡片资料」可修改释义、例句等内容，停笔约 0.6 秒、失去焦点或完成编辑时自动保存。普通设置会在选择或填完有效数字后自动提交。
4. 「词库管理」可搜索、排序、筛选、修改英文拼写和资料。删除会移入回收站。选择「提前复习」可查看已掌握卡片，选择「重新学习」会重置当天和长期进度。可选中多条或全选筛选结果，再批量处理。
5. 「设置」可分别改每日复习词数、当天连对次数、长期过关天数、音标显示及联网补充。界面会在找到系统的本地英语语音时显示发音按钮。词库行可以从更多按钮、Windows 右键或 Android 长按打开操作菜单。
6. 「设置 → 外观」可选择浅色、深色或跟随系统，选项立即应用并记在本机。可用导航回到当前复习卡。从设置返回会保留已展开的释义和备注。界面规范及平台细节见 [UI-DESIGN.md](UI-DESIGN.md)。
7. 「设置 → 学习 → 考试日期」可选择每年循环或指定日期。复习页显示剩余自然日。默认每年 12 月 20 日，循环的 2 月 29 日会走到下一次实际的闰日。考试日期随完整学习数据迁移。旧备份缺少日期时自动使用默认值。

## 离线记忆联想

卡片在中文释义下方统一显示「记忆联想」。程序将已有构词来源和本地字形线索合并，优先选择在当前拼写中出现的前、后缀和词干。通常直接显示三条，其余在「更多联想」中查看。显示的内容用于记忆，包括字形线索。现有词库会直接使用新版索引，释义、备注和历史无需迁移。资料来源及署名见 [Morphology-1.9.txt](licenses/Morphology-1.9.txt)。

## 双层复习规则

- 默认每天的常规额度为 20 个不同的词，设置提供 40 词档位以及自定义数量。每个词先完成当天连续正确 3 次，再累计 1 个过关学习日。默认连续 6 个过关学习日后长期掌握。不同词各自计数。
- 第一次作答才算开始该词当天的学习。当天临时离开或退出后，重新打开可继续之前的连对次数。当天答错只清零当天连对，若最终过关，照常累计 1 天。
- 换到下一个学习日时，如果该词上一学习日实际作答过但未过关，此前的连续过关天数从零重新累计。中间完全没答这个词的日期不会打断记录。
- 通过当天门槛的词退出今日队列。每日任务进度按过关的不同单词数计算，未过关时的多次答题不增加词数名额。重测目标约为 15 张其他卡片，优先安排不同的词。尚未作答就退出或只打开复习页不会消耗间隔。剩余候选少时，优先展示等待最久的卡片。
- 重复录入和手动重新学习会清除该词的当天连对、当天过关、长期天数及掌握状态。资料、备注和历史仍保留。某词当天已经累计过 1 个过关日时，即使重置后再次过关，当天也不会再累计。
- 修改当天目标后，当天未过关的词立即按新门槛计算。降低门槛时，已经连对到新目标的词当天过关。当天已经过关的词保留当日成绩。新长期目标在未掌握词下一次获得有效过关日时检查。已掌握的词保留掌握状态。
- 学习日从设备本地时间 05:00 开始。午夜到 04:59 仍属前一学习日。跨过边界时，正在显示的卡片先完成当前作答，之后切到新学习日。正在等待「下一单词」的上一个学习日卡片也可先结束。新写入的记录保留实际时间，旧记录沿用当时存下的日期。
- 新导入和重新导入的当日待学词优先首次出现。所有这些词都进入本次学习日的任务，可以超过常规上限。已经打开的当前卡片仍可作答，重测就绪的词会按原有间隔穿插。重新导入会保留资料和备注。
- `Ctrl+Z` 撤销今天最后一次仍可撤销的答题，并回退其连对、过关天数、队列和统计。原答题记录保留并标注已撤销。

## 当天重测顺序

每次作答后，未过关的词根据今天的作答位置安排重测。目标位置在相邻两个同词之间预留 13～17 张其他卡片。等待稍久的词会优先出现，通常间隔落在 12～18 张。到点的重测继续穿插在新词之间。跨 05:00 后，上一学习日未过关的重测词优先占用当天空余的旧词名额，间隔参考已记录的答题顺序。

重开程序或重新进入复习时，会用今天已经存下的答题历史恢复相对位置。作答历史、当日进度、长期掌握和已有备份沿用同一格式。1.2 的便携词库无需转换即可继续使用。

## 高分屏布局

复习页跟随窗口的逻辑视口宽度。宽窗口左列显示释义和例句，右列放备注和附加资料。长备注随内容增高，复习正文独立滚动，作答栏固定在窗口底部。窗口缩小时，双列自动改为单列。顶部只留今日过关进度和日期。

## 文件导入

每批最多 1,000 项。纯英文可用英文逗号、中文逗号或换行分隔。内部空格允许出现在短语中，大小写和首尾空格在查重时忽略。TXT、CSV、JSON 用 UTF-8。导入新词时，文件中的完整资料优先于词典内容。再次导入已有词的作用是重新学习，原资料保留，更新内容可用编辑入口。

有表头的 CSV 可以使用以下格式。只有 `word` 是必填列，其他列可按需要提供。

```csv
word,meaning,pos,ipa,ipaUK,ipaUS,examples,exampleTranslation,etymology,collocations,note,personalNote
crucial,至关重要的,形容词,,,,This is a crucial decision.,这是一个至关重要的决定。,,,,重点记住关键的
```

JSON 词表是对象数组，也可以用相同的字段名。

```json
[
  {"word":"fiscal","meaning":"财政的","pos":"形容词","personalNote":"财政政策"}
]
```

## 查词策略与来源

- 离线 ECDICT 可提供基础中文释义和音标。词性从其结构化释义标记提取。内置索引有 758,516 项。原始版本为 `39cfb9672c0906b63569e0453c2e6abfb9ab182a`，以 MIT 许可分发。https://github.com/skywind3000/ECDICT
- 离线例句索引覆盖 17,870 个词形，其中 13,388 个有 Tatoeba 中英句对，其余来自 Simple English Wiktionary。Tatoeba 例句保留英中两句的作者及句子编号，Simple English Wiktionary 来源可在卡片内打开。例句按词形匹配，覆盖的用法随句对而异。https://tatoeba.org/en/downloads  
  https://kaikki.org/simplewiktionary/rawdata.html
- 缺失项目可由官方 MediaWiki Action API 查询英文 Wiktionary，补充例句、真实词源、词性、可获得的英式和美式音标及少量中文译词。只提交英文词条。查到的字段保存在本地，已有资料保留。查词无需密钥。词源可能保留英文，词典和语料覆盖有限。界面会提示缺项，可重试或手动编辑。https://www.mediawiki.org/wiki/API:Parsing_wikitext
- 原创双语例句和记忆提示作为内置学习资料提供。程序不使用生成式 AI 编造缺失词源或翻译。第三方词条来源和许可可在界面查看。

## 本地数据与恢复

数据库为 EXE 实际所在目录同级的 `Data\vocabulary.db`。设置、词条和复习记录统一保存在 SQLite，程序首次启动时自动创建目录并初始化数据库。目录不可写时会显示实际路径和错误。可将 EXE 和整个 `Data` 一并挪到有写入权限的位置。

### Windows 升级

1. 关闭旧版背词本。若旧进程还在后台，等它退出，或在任务管理器中结束旧版进程。
2. 把新版 `LexiGo.exe` 放到原 EXE 所在的文件夹，保留同级 `Data`，再启动新版。若该文件夹没有 `Data\vocabulary.db`，新版会从 `%LOCALAPPDATA%\WordReview\vocabulary.db` 创建一致性副本，并通过完整性检查后放入 `Data`。原文件留在原处。
3. 如果两处已有不同的数据库，新版会使用同级 `Data` 并显示提示。要换用旧库时，可先分别备份两边，再在旧版导出 JSON，并在新版确认恢复。迁移不会把两个库合并。
4. 首次读取旧规则数据库时，先写入 `Data\backups\before-dual-memory-v2-*.json`，再用一次 SQLite 事务升级。旧词条、设置、备注、答题历史和已掌握状态保留。旧规则记住次数在词库里单独标注，当前未掌握词的双层进度从零开始。旧版导出的 JSON 仍可恢复，并应用相同的兼容规则。

移动或复制之前，关闭主窗口，等待程序退出，再带上 EXE 和整个 `Data`。升级时已有便携版的 `Data` 可以直接保留。程序运行中不要只拷贝 SQLite 主文件，因为最新提交可能还在数据库的 WAL 中。

### 备份

在「设置」点击「备份数据」可保存包括词条、备注、历史、回收站和设置的完整备份。「恢复备份」先要求确认覆盖范围，然后事务恢复。恢复前的快照写入 `Data\backups\before-restore.json`。旧版留有恢复前快照时，迁移也会尝试复制为 `Data\backups\legacy-before-restore.json`。

日常词表交换可用「词库管理」里的 CSV 导出。完整恢复学习状态请使用 JSON 备份。

### 在 Windows 和 Android 间迁移

1. 在当前设备打开「设置」。Windows 选择「导出数据」，Android 点击「导出数据」后选择「分享数据」或「保存到手机」。文件名类似 `WordReview-Learning-2026-11-16.json`。
2. 自行把文件传到另一台设备。打开「设置」→「导入数据」，并在系统选择器中选择该文件。
3. 检查生成时间、词条和今日任务摘要。选择「确认覆盖」后，程序自动备份接收端，再用文件中的完整状态替换接收端。想回到覆盖前的状态，可用同一入口导入这份自动快照。
4. 换回原设备时，在正在使用的设备上重新导出最新文件，再在原设备导入。

完整学习数据会保存当天任务及调度所需的已提交作答历史。两端仍处于同一个学习日时，可以继续已有任务。导入已结束学习日的快照时，按原跨日规则开始本机当前学习日。跨时区导致两端日期不一致且导出端学习日尚未结束时，等该学习日结束后再导入。自动快照位于应用数据目录的 `backups/before-transfer-*.json`。

Android 数据保存在应用私有目录 `files/StudyData`。卸载应用或清除应用数据之前，请用「导出数据」把快照保存到应用外。导入后可通过「导出覆盖前备份」将最近一次自动快照取出，再用「导入数据」恢复。完整数据含个人备注，请自行保管。

Android 2.1.3 使用独立包名 `cn.wordreview.app.lexigo.v213`，可与 2.1.2 及更早版本同时安装。若要迁移学习记录，在旧版用「设置 → 导出数据 → 保存到手机」保存完整 JSON，再在 2.1.3 用「设置 → 导入数据」恢复。迁移时可以保留旧版。

## 构建与测试

使用 Go 1.25 或更新版本。Windows PowerShell 在源码目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

脚本运行 Go 测试并生成 `dist\LexiGo.exe`。首次从源码构建需要取得 `go.mod` 和 `go.sum` 声明的依赖。已编入的词典、界面和应用图标无需重新下载。第三方依赖许可证见 `licenses/`，数据处理脚本在 `scripts/`。

也可用 `go test ./...` 单独测试核心规则。用 Python 3 运行 `python scripts/test_http.py 路径\LexiGo.exe` 可以在独立临时词库上测试离线工作流和中止进程后恢复。还可运行 `python scripts/test_portable.py .\dist\LexiGo.exe`，用独立临时目录验证 EXE 路径、移动后重新打开和隔离的旧库迁移。脚本经过 EXE 的 `--serve` 模式测试后端，WebView2 窗口的验证需在 Windows 上双击 EXE。

Android 的开发环境、签名方式和命令见 `android/README.md`。两端快照共用 `transfer.go` 中的版本化协议。文件是 UTF-8 JSON，SHA-256 校验针对原始数据负载字节。请直接传输文件，编辑或重新格式化可能使校验失效。文件大小限制为 128 MiB。
